❓ FAQ

▶
▶What is the value of a call option with $100 stock, $90 strike, 2 years to expiration, 30% volatility, and 4% risk-free rate?
The option is worth approximately $22.50. It's $10 in-the-money plus $12.50 in time value. Total value = intrinsic value + time value.
▶What factors affect option value?
Option value increases with: higher stock price, higher volatility, longer time to expiration, and higher risk-free rate. It decreases with higher strike price.
▶What is the difference between intrinsic value and time value in options?
Intrinsic value = stock price - strike price (for in-the-money options). Time value is the premium above intrinsic value. For a $100 stock and $90 strike, intrinsic value is $10. The remaining $12.50 is time value.
