❓ FAQ

▶
▶How diversified is a portfolio with 60% stocks, 30% bonds, and 10% real estate?
HHI = 60² + 30² + 10² = 4,600. This is moderately concentrated (above 2,500). Adding more assets (international stocks, commodities) would improve diversification.
▶What is a good HHI score for portfolio diversification?
HHI < 1,500 = well diversified. 1,500-2,500 = moderately concentrated. > 2,500 = concentrated. A 60/40 stock/bond portfolio has HHI of 5,200 — considered concentrated.
▶How many stocks do I need to be well diversified?
Research shows 20-30 stocks eliminates about 80% of company-specific risk. An index fund (500+ stocks) provides maximum diversification. A 10-stock portfolio has an HHI of 1,000 (well diversified) if equally weighted.
