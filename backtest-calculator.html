📖 How to read your results

▶

Final Value

The ending portfolio value after applying the historical returns.

Total Return

The total percentage gain over the entire period.

CAGR

The compound annual growth rate — the steady annual return that would produce the same final value.

❓ FAQ

▶
▶What returns should I use?
You can use historical returns of the S&P 500, a mutual fund, or any investment. Common periods: S&P 500 average is about 10% with significant year-to-year variation.
▶What if I have more or fewer returns than years?
If you enter fewer returns, the last return will be repeated. If you enter more, only the first N will be used (where N is the number of years).
